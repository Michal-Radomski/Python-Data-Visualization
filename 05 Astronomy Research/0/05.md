# What is Gaussian Kernel

A **Gaussian kernel** is a kernel whose values come from a Gaussian (bell‑shaped) function. It is widely used for smoothing,
blurring, and noise reduction in images, as well as in machine‑learning kernels like the RBF (Radial Basis Function)
kernel.[^1][^2][^3]

---

### In image processing

In convolution for images, a **Gaussian kernel** is a small matrix whose entries follow a 2D Gaussian distribution centered
at the middle pixel. When convolved with an image, it replaces each pixel with a weighted average of its neighbors, where
closer pixels receive higher weights, producing a smooth “Gaussian blur.”[^2][^8][^9]

This kernel is:

- **Symmetric** around the center.
- **Normalized** so the sum of entries is 1, so the overall brightness of the image stays roughly unchanged.[^7][^2]

---

### In machine learning (RBF kernel)

In settings like SVMs, the **Gaussian kernel** (often called RBF kernel) is a function that measures similarity between two
points $x$ and $x'$:

$$
K(x, x') = \exp\left(-\frac{\|x - x'\|^2}{2\sigma^2}\right),
$$

where $\sigma$ controls how “wide” the kernel is. It effectively maps data into a high‑(or infinite‑) dimensional space,
helping separate non‑linearly separable classes by emphasizing local patterns.[^1][^3]
