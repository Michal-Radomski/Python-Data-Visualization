A **convolution operation** is a mathematical way of combining two signals (or arrays) to produce a third, often used to
“filter” or transform data, especially in image processing and deep learning. A **kernel** (also called a _filter_ or _mask_)
is a small matrix that defines how this transformation is done. [lenovo](https://www.lenovo.com/us/en/glossary/convolution/)

---

### What convolution means (intuitively)

In simple terms, convolution slides the kernel over an input (for example, an image) and, at each position, computes a
weighted sum of nearby values. The result is a new “feature map” that highlights certain patterns, such as edges, textures,
or blurs, depending on the kernel. [lenovo](https://www.lenovo.com/us/en/glossary/convolution/)

For images, this means each pixel in the output is a function of its local neighborhood in the input, with the kernel’s
entries acting as weights. [en.wikipedia](<https://en.wikipedia.org/wiki/Kernel_(image_processing)>)

---

### What a kernel is

A **kernel** is a small matrix (often 3×3 or 5×5) whose values are chosen to implement a specific effect, like blurring,
sharpening, or edge detection. When the kernel slides over the image, it multiplies each overlapping pixel by the
corresponding kernel value and sums the results to get one output pixel.
[lenovo](https://www.lenovo.com/us/en/glossary/convolution/)

For example:

- A **blurring kernel** averages nearby pixels (most entries are equal and positive).
- An **edge‑detection kernel** uses positive and negative weights to emphasize rapid intensity changes.
  [en.wikipedia](<https://en.wikipedia.org/wiki/Kernel_(image_processing)>)

---

### Basic steps of a convolution operation

1. Place the kernel over a local region of the input (e.g., a 3×3 patch of an image).
   [lenovo](https://www.lenovo.com/us/en/glossary/convolution/)
2. Multiply each element of the kernel with the corresponding input value (element‑wise multiplication).
   [viso](https://viso.ai/deep-learning/convolution-operations/)
3. Sum all the products to get a single value for the output array at that position.
   [lenovo](https://www.lenovo.com/us/en/glossary/convolution/)
4. Slide the kernel across the entire input (usually by one pixel at a time) to fill the full output.
   [opencv](https://opencv.org/blog/image-filtering-using-convolution-in-opencv/)

This same idea generalizes to multi‑channel data (like RGB images or CNN feature maps), where separate or shared kernels are
applied to each channel. [developer.nvidia](https://developer.nvidia.com/discover/convolution)
