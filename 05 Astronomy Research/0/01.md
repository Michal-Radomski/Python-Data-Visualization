FITS (Flexible Image Transport System) is the standard file format used in astronomy to store scientific data such as images,
spectra, and tables, along with metadata like calibration, telescope, and observation details in a self‑describing header.
[heasarc.gsfc.nasa](https://heasarc.gsfc.nasa.gov/docs/heasarc/fits.html)

Below is a quick guide for Ubuntu.

---

## What FITS data is

- FITS files can contain 1‑D spectra, 2‑D images, 3‑D data cubes, or tabular data, not just “pictures.”
  [en.wikipedia](https://en.wikipedia.org/wiki/FITS)
- Each file starts with an ASCII header (the HDU header) that describes the data shape, units, world‑coordinate system (WCS),
  and origin; the actual data follows in one or more “HDUs” (Header‑Data Units).
  [cxc.cfa.harvard](https://cxc.cfa.harvard.edu/ciao/dictionary/fits.html)

## How to open FITS files on Ubuntu

### 1. Install basic tools

Open a terminal and install some common astronomy packages:

```bash
sudo apt update
sudo apt install python3-pip python3-numpy
pip3 install astropy matplotlib
```

`astropy` can read and inspect FITS files programmatically; `matplotlib` lets you display images.
[fits.gsfc.nasa](https://fits.gsfc.nasa.gov/fits_libraries.html)

### 2. View a FITS file from Python

Create a simple script (e.g., `view_fits.py`) in the same directory as your `file.fits`:

```python
from astropy.io import fits
import matplotlib.pyplot as plt

# Open the FITS file
with fits.open("file.fits") as hdul:
    hdul.info()  # show structure (HDUs)
    data = hdul[0].data  # usually image data is in HDU 0

if data is not None:
    plt.imshow(data, origin="lower", cmap="gray")
    plt.colorbar()
    plt.show()
```

Run it:

```bash
python3 view_fits.py
```

This shows the image and prints the header info.
[stackoverflow](https://stackoverflow.com/questions/67153252/read-fits-files)

### 3. Use a FITS viewer (GUI)

Install a GUI FITS viewer such as DS9 or Aladin:

- Install DS9 (very common in astronomy):

  ```bash
  sudo apt install saods9
  saods9
  ```

  Then use `File → Open` to load your `.fits` file. [astronomy.me](https://www.astronomy.me.uk/fits-software)

- Install Aladin Lite / desktop client or similar viewers if you prefer more interactive tools (check your Ubuntu repos or
  project websites). [astronomy.me](https://www.astronomy.me.uk/fits-software)

### 4. Command‑line inspection

If you only want to inspect headers or structure:

```bash
pip3 install astropy
python3 -c "
from astropy.io import fits
f = fits.open('file.fits')
f.info()
"
```

This prints how many HDUs there are and their types without opening a plot window.
[heasarc.gsfc.nasa](https://heasarc.gsfc.nasa.gov/docs/heasarc/fits_overview.html)
